# 🤖 Мой ИИ Telegram Бот

Личный ИИ-ассистент в Telegram на базе Claude AI.

## Что умеет бот

| Режим | Команда | Что делает |
|-------|---------|------------|
| 💬 Умный чат | `/mode` → Умный чат | Отвечает на любые вопросы |
| 📝 Конспект | `/mode` → Конспект | Делает структурированный конспект из текста |
| 📄 Реферат | `/mode` → Реферат | Пишет реферат по теме |
| 💻 Программист | `/mode` → Программист | Пишет и объясняет код |
| 🧮 Задачи | `/mode` → Задачи | Решает задачи пошагово |

---

## УСТАНОВКА И ЗАПУСК

### ШАГ 1 — Получи токен Telegram бота

1. Открой Telegram, найди **@BotFather**
2. Напиши `/newbot`
3. Придумай имя бота (например: `Мой ИИ Ассистент`)
4. Придумай username (например: `my_ai_helper_bot`) — должен заканчиваться на `bot`
5. BotFather даст тебе токен вида: `7123456789:AAF...`
6. **Сохрани этот токен!**

---

### ШАГ 2 — Получи БЕСПЛАТНЫЙ ключ Groq

1. Зайди на сайт: **https://console.groq.com**
2. Зарегистрируйся (можно через Google)
3. **ВАЖНО**: Никакой кредитной карты не требуется! 🎉
4. Перейди в **API Keys**
5. Нажми **Create API Key**
6. Скопируй ключ вида: `gsk_...`
7. **Готово!** Это совершенно бесплатно и без лимитов!

---

### ШАГ 3 — Настрой файл .env

1. Скопируй файл `.env.example` и переименуй в `.env`
2. Открой `.env` в любом текстовом редакторе (Блокнот)
3. Вставь свои ключи:

```
BOT_TOKEN=7123456789:AAF_твой_токен_здесь
GROQ_API_KEY=gsk_твой_ключ_здесь
```

---

### ШАГ 4 — ЗАПУСК

**Вариант 1: На Replit (бесплатный облачный хостинг, 24/7)**

1. Зайди на **https://replit.com** и зарегистрируйся
2. Нажми **Create** → **Import from GitHub**
3. Вставь ссылку на репозиторий
4. В левом меню нажми **Secrets** (иконка ключика)
5. Добавь переменные:
   - Key: `BOT_TOKEN` → Value: твой токен
   - Key: `GROQ_API_KEY` → Value: твой ключ
6. Нажми **Run** вверху — бот запущен!

**Вариант 2: На своем компьютере (локально)**

```bash
# Установи Python 3.10+
pip install -r requirements.txt

# Создай файл .env (скопируй из .env.example и заполни)
cp .env.example .env

# Запусти бота
python main.py
```

Компьютер должен быть включен 24/7 для работы бота. Если выключишь — бот не будет отвечать.

## ✨ Бонус: Альтернативные модели Groq

Groq поддерживает несколько моделей (все бесплатны):

| Модель | Скорость | Качество | Использование |
|--------|----------|----------|------------|
| `mixtral-8x7b-32768` | ⚡⚡⚡ Супер быстро | Отличное | По умолчанию |
| `llama-3.1-8b-instant` | ⚡⚡⚡ Супер быстро | Хорошее | Простые вопросы |
| `llama-3.1-70b-versatile` | ⚡⚡ Быстро | Отличное | Сложные задачи |

Чтобы изменить модель, отредактируй в `config.py`:
```python
AI_MODEL = "llama-3.1-70b-versatile"  # более умная
```

## Частые вопросы

**Это правда бесплатно?**
Да! Groq полностью бесплатный, без ограничений на количество запросов. Никакой карты не требуется.

**Есть лимиты?**
Нет! Groq позволяет неограниченное количество запросов бесплатно.

**Почему Groq?**
- ✅ Полностью бесплатно (без карты!)
- ✅ Не требует регистрации кредитных данных
- ✅ Неограниченные запросы
- ✅ Очень быстрый ответ (< 1 сек)
- ✅ Поддерживает сложные модели

**Качество AI ниже, чем Claude?**
Groq использует модель Mixtral (очень хороша). Для большинства задач качество отличное. Если нужен именно Claude — можешь изменить API ключ и модель в `config.py`.

**Как запустить 24/7?**
- На Replit (бесплатно) — он держит бот включенным
- На своем ПК/сервере — компьютер должен быть включен
- На VPS (платно)
